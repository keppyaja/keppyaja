## `$ whoami`

Hi! I'm **Tsaqif Fawwaz**, better known online as **Skipped**. I'm a **D4 Informatics Engineering student at Politeknik Elektronika Negeri Surabaya** who enjoys turning curiosity into working software, solving CTF challenges, and understanding how systems can be made more secure.

My interests sit at the intersection of:

- **Cybersecurity** — web exploitation, binary exploitation, cryptography, reverse engineering, and forensics
- **Competitive problem solving** — algorithms, mathematics, and CTF challenges
- **Web development** — responsive interfaces, Laravel applications, and static sites
- **Knowledge sharing** — documenting solutions so the next challenge becomes easier

```text
focus   →  cybersecurity + software engineering
learn   →  one vulnerability, algorithm, and better abstraction at a time
build   →  useful tools, readable write-ups, and interfaces with personality
```
